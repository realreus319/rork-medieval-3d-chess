# 楚汉棋局 · 电影化 3D 中国象棋

这是对 [alexngdev99/rork-medieval-3d-chess](https://github.com/alexngdev99/rork-medieval-3d-chess) 的中国象棋改造版本。

本项目现在采用正确的分层方式：

- **规则层**改为完整中国象棋：9×10、楚河汉界、九宫、蹩马腿、塞象眼、炮架、兵卒过河、将帅照面与自陷禁手。
- **表现层**继续使用原项目的电影化 3D 系统：原版角色模型、骨骼动画、行军脚步、近战攻击、远程法术、受击死亡、燃烧消散、粒子、震屏、镜头推进和战场环境。

不再使用普通圆盘棋子作为主视图。

## 已实现

- 原版两支 3D 阵营和角色模型恢复
- 原版 idle / walk / run / attack / death 动画恢复
- 原版近战攻击、法术攻击、死亡呼喊、燃烧消散和战场粒子恢复
- 原版电影化吃子镜头、震屏、落地和棋盘冲击效果恢复
- 9×10 电影化中国象棋棋盘、楚河汉界和九宫
- 帅/将、仕/士、相/象、马、车、炮/砲、兵/卒完整走法
- 人机对弈、本地双人、三级 AI、执红或执黑
- 中文 / English 界面，默认简体中文并记忆语言选择
- 悔棋、重新开局、棋谱、已吃棋子、镜头翻转和俯视视角

## 角色映射

原项目有六套电影化角色原型，中国象棋有七类棋子。当前采用以下表现映射，规则身份不会丢失：

| 中国象棋棋子 | 原版表现原型 | 吃子演出 |
| --- | --- | --- |
| 帅 / 将 | King | 审判柱、重击、冲击波 |
| 炮 / 砲 | Queen | 远程多重法术 |
| 仕 / 士 | Bishop | 远程法术 |
| 马 | Knight | 冲锋与跃进攻击 |
| 车 | Rook | 重甲近战与地面冲击 |
| 相 / 象 | Rook | 重甲近战与地面冲击 |
| 兵 / 卒 | Pawn | 近战刺击 |

后续可以在不改变规则的前提下，为相/象增加独立角色模型。

## 开发

```bash
cd web
npm install
npm run dev
npm run build
npm test
```

要求 Node.js 20+。项目是纯静态站点，无需后端或环境变量。

## 规则边界

当前覆盖日常合法对局、将军与无合法着法判负。赛事级长将、长捉和复杂循环局面裁决仍需后续增加专门裁判模块。
