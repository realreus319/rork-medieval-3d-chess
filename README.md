# 楚汉棋局 · 电影化 3D 中国象棋

这是对 [alexngdev99/rork-medieval-3d-chess](https://github.com/alexngdev99/rork-medieval-3d-chess) 的中国象棋改造版本。

本项目采用明确的三层结构：

- **产品外壳**统一沿用原版 `GameShell`：电影化开场、金边主菜单、设置弹窗、对局 HUD、棋谱与终局弹窗。
- **规则层**为完整中国象棋：9×10、楚河汉界、九宫、蹩马腿、塞象眼、炮架、兵卒过河、将帅照面与自陷禁手。
- **表现层**继续使用原项目的电影化 3D 系统：角色模型、骨骼动画、行军脚步、攻击、法术、受击死亡、燃烧消散、粒子、震屏、镜头和战场环境。

不再使用普通圆盘棋子，也不再另起一套普通网页 UI。

## 已实现

- 原版 `GameShell` 产品外壳恢复并作为后续唯一 UI 基础
- 原版电影化开场、主菜单、设置弹窗、HUD、棋谱与终局弹窗
- 四种战场、四档画质、亮度、安全渲染、声音、电影化吃子镜头与身份徽标设置
- 原版两支 3D 阵营和 idle / walk / run / attack / death 动画
- 近战攻击、法术攻击、死亡呼喊、燃烧消散、粒子、震屏和棋盘冲击
- 9×10 中国象棋棋盘、楚河汉界和九宫
- 帅/将、仕/士、相/象、马、车、炮/砲、兵/卒完整走法
- 相/象拥有独立的第七种渲染身份、3D 礼仪护具、攻击重量、徽标和俯视标志
- 人机对弈、本地双人、三级 AI、执红或执黑
- 中文 / English 界面，默认简体中文并记忆选择
- 悔棋、棋谱、已吃棋子、镜头翻转和俯视视角

## 七种角色表现

| 中国象棋棋子 | 电影化表现 | 吃子演出 |
| --- | --- | --- |
| 帅 / 将 | King / General | 审判柱、重击、冲击波 |
| 炮 / 砲 | Cannon caster | 远程多重法术 |
| 仕 / 士 | Advisor mage | 远程法术 |
| 相 / 象 | Elephant guardian | 独立礼仪护具、玉色冲击波与专属徽记 |
| 马 | Horse / Knight | 冲锋与跃进攻击 |
| 车 | Chariot / Rook | 重甲近战与地面冲击 |
| 兵 / 卒 | Soldier | 近战刺击 |

相/象的规则身份、渲染类型、上方徽标、俯视标志、移动重量和攻击参数均与车分离。

## 规则验证

规则测试覆盖：

- 将帅九宫与照面
- 仕士斜行
- 相象走田、塞象眼与不过河
- 马走日与蹩马腿
- 车的全方向直线移动、跨河深入敌阵和吃子
- 车被钉在帅前时禁止横走暴露主帅
- 炮的非吃子移动、炮架和隔子吃子
- 兵卒过河前后行为
- 自陷将军禁手、吃将和无合法着法判负
- 全部 90 个逻辑坐标与 3D 场景坐标往返

## 开发

```bash
cd web
npm install
npm run dev
npm run build
npm test
```

要求 Node.js 20+。项目是纯静态站点，无需后端或环境变量。

## 规则边界

当前覆盖日常合法对局、将军与无合法着法判负。赛事级长将、长捉和复杂循环局面裁决仍需后续增加专门裁判模块。
